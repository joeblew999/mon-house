# เพดาน - แหลมฉบัง

ห้องรับแขกขยายให้ใหญ่ 7m × 7m โดยการถอดกำแพงที่รองรับน้ำหนักและติดตั้งเหล็กคาน เพดานแบบแขวน (เมทัลกริด + แผ่น) ที่มีอยู่จะยังคงอยู่ แผ่นเบอร์โดว์ใหม่ติดกับด้านล่างของเมทัลกริดที่มีอยู่ การปูฉนวนกระดาษฟอยล์บนแผ่นที่มีอยู่เพื่อลดความร้อน การสร้างชั้นลอยด้านล่างของแผ่นราบพร้อมแถบ LED ส่องสว่างและไฟดาวน์ไลท์ในแผงกลาง

**ลำดับการทำงาน: โครงสร้าง (คาน + กำแพง) → ฉนวน + แผ่นเบอร์โดว์ราบ → ชั้นลอย → แผ่นชั้นลอย → เทป + เซต + สี → แถบ LED
