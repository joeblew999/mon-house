# วินโดว์ และ ประตู - ล่าแมชบัง

เปลี่ยนวินโดว์ไม้โบราณและประตูเลื่อนอลูมิเนียมทั้งหมด ออกฟลายสกรีนและกรองเหล็กกันขโมยเก่า

**FRAMEX ทั้งหมด สีอลูมิเนียมดำ ไม่ใช่ uPVC** ผลิตโดย Window Asia มีจำหน่ายที่ Thai Watsadu, OfficeMate หรือซื้อตรงจาก Window Asia
