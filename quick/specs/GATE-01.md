# Gate — Phase 01: Motor on Existing Gate

Phase 01 work, do now. Make the existing gate functional with a remote-controlled motor so Mon can drive into the garage easily. Phase 02 (gate replacement) is a separate spec — see [GATE-02](GATE-02.md). The motor installed in this phase **is reused on the Phase 02 replacement gate**.

**Quote rule:** this file is **one quote line item**. The builder gives a single number for the **GATE PHASE 01 TOTAL** — not bundled with any other spec, not split across files. 1:1 mapping between this spec and the quote. (The painting line at the bottom is Joe + Mon DIY, not in the builder's quote.)

Goal: existing gate slides easily and opens by remote so Mon can get her car into the garage without effort. Bottom chord and wheels get replaced; everything else on the gate stays.

## Bottom chord and wheels (existing gate)

- Cut out the rusted bottom steel chord of the existing gate.
- Weld in a new bottom steel chord.
- Fit 2 new wheels to the new bottom chord.
- Result: the gate slides easily on the existing runner rail.

## Vertical catcher post (existing)

- Check alignment of the vertical post that the gate slides into when closed.
- Adjust if needed so the gate seats cleanly against the post — the new bottom chord and wheels may shift the gate's closed position slightly.
- This is alignment-only. No replacement, no rebuild.

## Electric motor on the existing gate

- Install an electric sliding-gate motor on the existing gate.
- Supply 2 remotes for opening and closing.
- Once the motor is in, **no lock is needed** — the motor holds the gate closed.

## Power to the motor

- The builder runs power from a suitable existing source to the new motor location.
- Proper fuse for the motor circuit.

## Constraints for Phase 02 reuse

- Choose a motor that can be **reused on the [Phase 02](GATE-02.md) replacement gate**. Phase 02 will reuse the same motor — do not pick a model that locks us into the existing gate.
- **Mount the motor so it can be raised later.** The Phase 02 gate has a different height, so the rack (saw-tooth linear rail) attached to the gate will sit at a different height than it does on the existing gate. The motor mount (bracket, plinth, or base plate) must allow the motor to be lifted to a new height in Phase 02 without re-pouring concrete or relocating the power feed.

## Painting (Joe + Mon, after the builder is finished)

The old gate is rusted and flaking — repainting **is** part of Phase 01 work, done by Joe + Mon after the builder welds in the new bottom chord. **This is not in the builder's Phase 01 quote** (DIY, not builder labour), but it is happening.

Procedure:

- **Wire brush** loose rust and flaking paint off the gate first.
- **Paint:** `metal-2in1` — full product details inlined below from the shared catalog partial. Same product used on the [ROOF](ROOF.md) beams. See [PAINT.md](PAINT.md) for the formula and project-wide rollup.
- 2 coats. Recoat after 1–2 hours.
- **Paint area:** ~12 m² (both sides of the gate, TBC by direct measurement).
- **Cans:** `ceil(12 ÷ 3.5)` = **4 cans** (effective coverage 3.5 m²/can). Subtotal ~800 THB.
