# Bathroom basic refresh — Laem Chabang

The cheapest sensible bathroom upgrade. **No walls move. No wall tiles touched. No basin replaced. No shower work.** Existing **1380 × 1950 mm** footprint kept as-is.

Scope is the bare essentials: new toilet + bidet, new floor tiles, new mirror, new wall cabinet (DIY).

This is **PHASE 02 only** — see [PHASES](AAA-PHASES.md). Decide between this file, [BATHROOM-COMPACT.md](BATHROOM-COMPACT.md), and [BATHROOM_ENLARGE.md](BATHROOM_ENLARGE.md) before quoting.

**Quote rule:** this file is **one quote line item**. The builder gives a single number for the **BATHROOM TOTAL** — not bundled with any other spec, not split across files. 1:1 mapping between this spec and the quote.

## What gets replaced

1. **Toilet** — old pan + cistern + seat out; new compact close-coupled in roughly the same position.
2. **Bidet sprayer** — new stainless, off the toilet cold inlet.
3. **Floor tiles** — strip existing floor tiles, lay new ones across the whole bathroom floor. **Walls keep their existing tiles.**
4. **Floor drain** — full drain unit replaced (not just the grate). The floor is being stripped to slab for the new tiles, so swapping the whole drain body is essentially free labour-wise. Existing drain **outlet location** stays — no re-routing of the under-slab waste line.
5. **Mirror** — new full-width frameless mirror above the existing basin and toilet.
6. **Wall cabinet** — MOYA TK-CAB-007 wall-hung cabinet (DIY by Joe + Mon, **not in builder quote**).

## What stays untouched

- **Basin + taps + trap + waste** — existing, in current position.
- **Shower head + mixer + water heater + supply pipework** — existing, in current positions, not moved, not replaced.
- **Wall tiles** — existing, kept as-is across all walls. **No new wall tiles, no wall retiling.** Builder re-silicones wet-edge corners only as needed for cleanliness when the new floor tiles meet the existing wall tile.
- **Door + frame + lock** — existing, no change.
- **Floor drain outlet + soil pipe + waste pipe (under-slab)** — unchanged. Drain *body* gets replaced (see "What gets replaced") but the under-slab waste line is reused as-is — no re-routing.
- **Ceiling + light fitting + light switch** — existing, no change. Whole-house lighting refresh is a separate later scope.
- **Power outlets + electrical circuits** — existing, no new outlets, no new circuits, no RCD/GFCI work in this scope.
- **Painted walls** — existing paint kept.
- **Existing 50 mm wet-zone step** — kept exactly as today.

**Aesthetic note (accepted trade-off):** new modern floor tile next to the existing dated wall tiles will read as a mismatch. That is the conscious cost of staying basic — if the mismatch becomes intolerable, the upgrade path is BATHROOM-COMPACT (full retile, no wall move) without scrapping any of the BASIC fixtures.

---

## Toilet position

The new toilet stays in **roughly the existing position** so the soil-pipe spigot doesn't need to move. Builder confirms on site, **before quoting**, that the new compact pan's rough-in (305 mm) lines up with the existing soil pipe. If it does not align, raise it as a separate cost line — do not bundle re-routing into the BASIC quote.

Bidet sprayer mounts via a **tank-clip bracket** off the toilet's cold-water inlet — **no drilling into the existing wall tiles**, hose runs hidden behind the cistern.

## Steps (order of work)

1. **Pre-quote site check.** Builder confirms the new compact pan's 305 mm rough-in lines up with the existing soil pipe. If it doesn't, raise it before quoting — do not bundle re-routing.
2. **Strip out.** Remove existing floor tiles, existing toilet pan + cistern + seat, existing floor drain (full unit). **Disconnect — do not remove or move** — the basin, shower head, mixer, water heater.
3. **Floor levels.** Thin-mortar bed restoring the existing fall toward the existing drain across the whole bathroom floor. **No slab work** — no digging, no building up. The 50 mm wet-zone step stays exactly as today.
4. **Floor tiles.** Lay across both zones (entry/basin zone + wet zone). Maintain the existing 50 mm step with a clean square edge. Anti-slip is not strictly required for BASIC, but if the builder recommends a matched anti-slip variant for the wet zone strip, accept it. Clean silicone bead at the floor-to-wall junction where the new floor tile meets the existing wall tile.
5. **Sanitary + drain.** Fit new floor drain (COTTO CT6404Z2P) onto the existing under-slab waste outlet — bed it level with the new tile finish. Fit new toilet pan + cistern + seat in roughly the existing position. Fit new stainless bidet sprayer with T-valve off cold supply (tank-clip mount, no drilling into wall tile).
6. **Mirror.** Fix the new full-width frameless mirror to the existing wall tiles above the basin and toilet — mirror adhesive + hidden top clips, silicone butt at each vertical end.
7. **Test + commission.** Fill the toilet cistern, run the bidet sprayer, check drain run-off, confirm no leaks. Confirm the existing shower / basin still work (they were only disconnected at the wall stop-cocks if needed).

After the builder is done — **DIY by Joe + Mon, not in builder quote:**

- Install MOYA TK-CAB-007 cabinet on the wall opposite the toilet (DEXZON HNA-8 anchors into masonry, bottom edge at 1100 mm AFL).

## Phase 02 BASIC scope is fixed — nothing else

The BASIC quote covers **only** the items above. Do **not** add to the quote:

- **No new wall tiles, no wall retiling, no wall re-grout** beyond cleaning up the floor-to-wall silicone junction.
- **No basin / no basin taps / no basin trap work.**
- **No shower work** — no new mixer, no new shower head, no new water heater, no shower repositioning.
- **No glass partition.**
- **No wall demolition, no new wall, no door work.**
- **No electrical work** — no switch move, no new outlets, no RCD/GFCI fitting, no light fitting change.
- **No painting** — existing paint kept.
- **No ceiling work, no vent / extractor fan.**
- **No re-routing of soil / waste / supply pipework** beyond the toilet's local connection.
- **No bathroom door change.**

If the builder finds something during strip-out (hidden leak, broken supply line, rotten substrate, soil-pipe misalignment) that genuinely needs more work, **raise it separately before quoting** — do not bundle it into the BASIC line item.

## Open items (to confirm before quoting)

- **Soil-pipe alignment** — confirm the existing soil pipe lines up with the new compact pan's 305 mm rough-in. If not, agree the extra cost separately.
- **Existing wall-tile condition** — confirm the existing wall tiles are sound enough to stay (no loose tiles, no cracked grout that would force partial wall work). If a small remedial fix is needed, raise it as a separate optional line.
- **Shower stop-cock / supply isolation** — confirm the basin and shower can be isolated at existing valves during the floor-tile strip-out without forcing any pipework moves.
