# ปรับปรุงห้องน้ำแบบพื้นฐาน — แหลมฉบัง

การอัปเกรดห้องน้ำที่ประหยัดที่สุดอย่างสมเหตุสมผล **ไม่ย้ายผนัง ไม่แตะกระเบื้องผนัง ไม่เปลี่ยนอ่างล้างหน้า ไม่ทำงานฝักบัว** คงขนาดพื้นที่เดิม **1380 × 1950 มม.** ตามเดิม

ขอบเขตงานคือสิ่งจำเป็นขั้นพื้นฐานเท่านั้น ได้แก่ โถสุขภัณฑ์ + ฝักบัวชำระใหม่ กระเบื้องปูพื้นใหม่ กระจกเงาใหม่ และตู้แขวนผนังใหม่ (DIY)

นี่คือ **PHASE 02 เท่านั้น** — ดู [PHASES](AAA-PHASES.md) ตัดสินใจเลือกระหว่างไฟล์นี้ [BATHROOM-COMPACT.md](BATHROOM-COMPACT.md) และ [BATHROOM_ENLARGE.md](BATHROOM_ENLARGE.md) ก่อนเสนอราคา

**กฎการเสนอราคา:** ไฟล์นี้คือ **รายการเสนอราคาหนึ่งบรรทัด** ผู้รับเหมาให้ตัวเลขเดียวสำหรับ **BATHROOM TOTAL** — ไม่รวมกับสเปคอื่น ไม่แบ่งย่อยข้ามไฟล์ จับคู่ 1:1 ระหว่างสเปคนี้กับใบเสนอราคา

---## สิ่งที่จะถูกเปลี่ยนใหม่

1. **โถสุขภัณฑ์** — รื้อโถ + หม้อน้ำ + ฝารองนั่งเดิมออก ติดตั้งโถสุขภัณฑ์แบบชิ้นเดียวขนาดกะทัดรัดในตำแหน่งใกล้เคียงเดิม
2. **สายฉีดชำระ** — ติดตั้งสายฉีดชำระสแตนเลสใหม่ ต่อจากท่อน้ำเย็นของโถสุขภัณฑ์
3. **กระเบื้องปูพื้น** — รื้อกระเบื้องพื้นเดิมออก ปูกระเบื้องใหม่ทั่วพื้นห้องน้ำทั้งหมด **ผนังคงกระเบื้องเดิมไว้**
4. **ท่อระบายน้ำพื้น** — เปลี่ยนชุดท่อระบายทั้งชุด (ไม่ใช่แค่ตะแกรง) เนื่องจากต้องรื้อพื้นลงถึงพื้นคอนกรีตเพื่อปูกระเบื้องใหม่อยู่แล้ว การเปลี่ยนตัวท่อระบายทั้งชุดจึงแทบไม่มีค่าแรงเพิ่ม **ตำแหน่งทางออกของท่อระบาย**คงเดิม — ไม่ต้องเดินท่อน้ำทิ้งใต้พื้นใหม่
5. **กระจกเงา** — ติดตั้งกระจกเงาแบบไร้กรอบเต็มความกว้างใหม่ เหนืออ่างล้างหน้าและโถสุขภัณฑ์เดิม
6. **ตู้แขวนผนัง** — ตู้แขวนผนัง MOYA รุ่น TK-CAB-007 (Joe และ Mon ติดตั้งเอง **ไม่รวมในใบเสนอราคาของผู้รับเหมา**)## สิ่งที่ไม่มีการเปลี่ยนแปลง

- **อ่างล้างหน้า + ก๊อกน้ำ + ท่อดักกลิ่น + ท่อน้ำทิ้ง** — ของเดิม คงอยู่ตำแหน่งปัจจุบัน
- **ฝักบัว + วาล์วผสมน้ำ + เครื่องทำน้ำอุ่น + ท่อจ่ายน้ำ** — ของเดิม คงอยู่ตำแหน่งปัจจุบัน ไม่ย้าย ไม่เปลี่ยน
- **กระเบื้องผนัง** — ของเดิม คงไว้ตามสภาพทุกผนัง **ไม่มีการติดกระเบื้องผนังใหม่ ไม่มีการปูกระเบื้องผนังใหม่** ผู้รับเหมายาซิลิโคนใหม่เฉพาะมุมรอยต่อเขตเปียกตามความจำเป็นเพื่อความเรียบร้อยบริเวณที่กระเบื้องพื้นใหม่จรดกระเบื้องผนังเดิมเท่านั้น
- **ประตู + วงกบ + กลอน** — ของเดิม ไม่มีการเปลี่ยนแปลง
- **ช่องระบายน้ำที่พื้น + ท่อโสโครก + ท่อน้ำทิ้ง (ใต้พื้นคอนกรีต)** — ไม่เปลี่ยนแปลง *ตัว* ช่องระบายน้ำจะถูกเปลี่ยนใหม่ (ดูหัวข้อ "สิ่งที่ถูกเปลี่ยนใหม่") แต่ท่อน้ำทิ้งใต้พื้นคอนกรีตใช้ของเดิมตามสภาพ — ไม่มีการเดินท่อใหม่
- **ฝ้าเพดาน + ดวงโคม + สวิตช์ไฟ** — ของเดิม ไม่มีการเปลี่ยนแปลง การปรับปรุงระบบไฟทั้งบ้านเป็นขอบเขตงานแยกในภายหลัง
- **เต้ารับไฟฟ้า + วงจรไฟฟ้า** — ของเดิม ไม่มีเต้ารับใหม่ ไม่มีวงจรใหม่ ไม่มีงาน RCD/GFCI ในขอบเขตนี้
- **ผนังที่ทาสี** — คงสีเดิมไว้
- **ขั้นเขตเปียกเดิมขนาด 50 มม.** — คงไว้ตามสภาพปัจจุบันทุกประการ

**หมายเหตุด้านความสวยงาม (ข้อแลกเปลี่ยนที่ยอมรับได้):** กระเบื้องพื้นใหม่แบบสมัยใหม่ที่อยู่ติดกับกระเบื้องผนังเดิมที่ดูล้าสมัยจะดูไม่เข้ากัน นี่คือต้นทุนที่ตั้งใจรับเพื่อให้งานอยู่ในระดับพื้นฐาน — หากความไม่เข้ากันนี้กลายเป็นสิ่งที่รับไม่ได้ แนวทางการอัปเกรดคือ BATHROOM-COMPACT (ปูกระเบื้องผนังใหม่ทั้งหมด โดยไม่ย้ายผนัง) โดยไม่ต้องทิ้งสุขภัณฑ์ใดๆ ที่ติดตั้งใน BASIC

---## ตำแหน่งโถสุขภัณฑ์

โถสุขภัณฑ์ใหม่ยังคงอยู่ใน **ตำแหน่งเดิมโดยประมาณ** เพื่อไม่ต้องย้ายปลายท่อน้ำทิ้ง ผู้รับเหมายืนยันที่หน้างาน **ก่อนเสนอราคา** ว่าระยะ rough-in ของโถสุขภัณฑ์รุ่นกะทัดรัดใหม่ (305 มม.) ตรงกับท่อน้ำทิ้งเดิม หากไม่ตรงกัน ให้แจ้งเป็นรายการค่าใช้จ่ายแยกต่างหาก — ห้ามรวมค่าเดินท่อใหม่เข้าไปในใบเสนอราคาแบบ BASIC

สายฉีดชำระติดตั้งผ่าน **คลิปยึดถังพักน้ำ** ที่ต่อจากท่อน้ำเย็นของโถสุขภัณฑ์ — **ไม่เจาะกระเบื้องผนังเดิม** เดินสายซ่อนไว้ด้านหลังถังพักน้ำ

---## ขั้นตอน (ลำดับการทำงาน)

1. **ตรวจหน้างานก่อนเสนอราคา** ผู้รับเหมายืนยันว่าระยะ rough-in 305 mm ของโถสุขภัณฑ์ขนาดกะทัดรัดตัวใหม่ตรงกับท่อโสโครกเดิม หากไม่ตรง ให้แจ้งก่อนเสนอราคา — ห้ามรวมงานเดินท่อใหม่ไว้ในใบเสนอราคา
2. **รื้อถอน** รื้อกระเบื้องพื้นเดิม โถสุขภัณฑ์ + หม้อน้ำ + ฝารองนั่งเดิม และตะแกรงระบายน้ำพื้นเดิม (ยกชุด) **ถอดท่อออก — ห้ามรื้อหรือย้าย** อ่างล้างหน้า ฝักบัว ก๊อกผสม และเครื่องทำน้ำอุ่น
3. **ระดับพื้น** ปูปูนทรายบาง ๆ เพื่อคืนความลาดเอียงเดิมไปยังตะแกรงระบายน้ำเดิมตลอดพื้นห้องน้ำทั้งหมด **ไม่มีงานพื้นคอนกรีตโครงสร้าง** — ไม่ขุด ไม่ก่อขึ้น ขั้นบันไดโซนเปียก 50 mm คงไว้เหมือนเดิมทุกประการ
4. **กระเบื้องพื้น** ปูครอบคลุมทั้งสองโซน (โซนทางเข้า/อ่างล้างหน้า + โซนเปียก) คงขั้นบันได 50 mm เดิมไว้พร้อมขอบฉากที่เรียบร้อย ไม่จำเป็นต้องเป็นกระเบื้องกันลื่นสำหรับสเปก BASIC แต่หากผู้รับเหมาแนะนำกระเบื้องกันลื่นรุ่นที่เข้าชุดกันสำหรับแถบโซนเปียก ให้ยอมรับได้ ยิงซิลิโคนรอยต่อสะอาดเรียบร้อยที่จุดบรรจบระหว่างกระเบื้องพื้นใหม่กับกระเบื้องผนังเดิม
5. **สุขภัณฑ์ + ตะแกรงระบายน้ำ** ติดตั้งตะแกรงระบายน้ำใหม่ (COTTO CT6404Z2P) บนช่องระบายน้ำใต้พื้นเดิม — ฝังให้ระดับเสมอกับผิวกระเบื้องใหม่ ติดตั้งโถสุขภัณฑ์ + หม้อน้ำ + ฝารองนั่งใหม่ในตำแหน่งเดิมโดยประมาณ ติดตั้งสายฉีดชำระสเตนเลสใหม่พร้อมวาล์วสามทางต่อจากท่อน้ำเย็น (ใช้คลิปเกี่ยวหม้อน้ำ ไม่ต้องเจาะกระเบื้องผนัง)
6. **กระจกเงา** ติดกระจกเงาเต็มแนวแบบไม่มีกรอบบานใหม่บนกระเบื้องผนังเดิมเหนืออ่างล้างหน้าและโถสุขภัณฑ์ — ใช้กาวติดกระจก + คลิปยึดด้านบนแบบซ่อน ยิงซิลิโคนชนขอบที่ปลายแนวตั้งทั้งสองด้าน
7. **ทดสอบ + ส่งมอบ** เติมน้ำในหม้อน้ำโถสุขภัณฑ์ ทดลองใช้สายฉีดชำระ ตรวจการระบายน้ำที่ตะแกรง ยืนยันว่าไม่มีจุดรั่วซึม ยืนยันว่าฝักบัว/อ่างล้างหน้าเดิมยังใช้งานได้ตามปกติ (ถ้าจำเป็นถูกถอดออกที่วาล์วปิดบนผนังเท่านั้น)

หลังผู้รับเหมาทำงานเสร็จแล้ว — **DIY โดย Joe + Mon ไม่อยู่ในใบเสนอราคาผู้รับเหมา:**

- ติดตั้งตู้ MOYA TK-CAB-007 บนผนังด้านตรงข้ามโถสุขภัณฑ์ (พุก DEXZON HNA-8 ยึดเข้าผนังก่ออิฐ ขอบล่างที่ระดับ 1100 mm AFL)

---## ขอบเขต Phase 02 BASIC คงที่ — ไม่มีรายการอื่น

ใบเสนอราคา BASIC ครอบคลุม**เฉพาะ**รายการข้างต้นเท่านั้น **ห้าม**เพิ่มรายการต่อไปนี้เข้าในใบเสนอราคา:

- **ไม่มีการปูกระเบื้องผนังใหม่ ไม่มีการปูกระเบื้องผนังซ้ำ ไม่มีการยาแนวผนังใหม่** นอกเหนือจากการเก็บงานซิลิโคนรอยต่อระหว่างพื้นกับผนัง
- **ไม่มีงานอ่างล้างหน้า / ไม่มีงานก๊อกอ่างล้างหน้า / ไม่มีงานท่อดักกลิ่นอ่างล้างหน้า**
- **ไม่มีงานฝักบัว** — ไม่มีวาล์วผสมใหม่ ไม่มีหัวฝักบัวใหม่ ไม่มีเครื่องทำน้ำอุ่นใหม่ ไม่มีการย้ายตำแหน่งฝักบัว
- **ไม่มีฉากกั้นกระจก**
- **ไม่มีการทุบผนัง ไม่มีการก่อผนังใหม่ ไม่มีงานประตู**
- **ไม่มีงานไฟฟ้า** — ไม่มีการย้ายสวิตช์ ไม่มีการติดตั้งปลั๊กใหม่ ไม่มีการติดตั้ง RCD/GFCI ไม่มีการเปลี่ยนโคมไฟ
- **ไม่มีงานทาสี** — คงสีเดิมไว้
- **ไม่มีงานฝ้าเพดาน ไม่มีช่องระบายอากาศ / พัดลมดูดอากาศ**
- **ไม่มีการเดินท่อใหม่ของท่อโสโครก / ท่อน้ำทิ้ง / ท่อน้ำดี** นอกเหนือจากการเชื่อมต่อเฉพาะจุดของโถสุขภัณฑ์
- **ไม่มีการเปลี่ยนประตูห้องน้ำ**

หากผู้รับเหมาพบปัญหาในระหว่างการรื้อถอน (การรั่วซึมที่ซ่อนอยู่ ท่อน้ำดีชำรุด พื้นผิวรองผุพัง การวางแนวท่อโสโครกไม่ตรง) ที่จำเป็นต้องทำงานเพิ่มเติมจริง ๆ ให้**แจ้งแยกต่างหากก่อนเสนอราคา** — ห้ามรวมเข้าไปในรายการ BASIC

---## รายการที่ต้องยืนยัน (ก่อนเสนอราคา)

- **แนวท่อโสโครก** — ยืนยันว่าท่อโสโครกเดิมตรงแนวกับระยะ rough-in 305 มม. ของโถสุขภัณฑ์รุ่นกะทัดรัดตัวใหม่ หากไม่ตรง ให้ตกลงค่าใช้จ่ายส่วนเพิ่มแยกต่างหาก
- **สภาพกระเบื้องผนังเดิม** — ยืนยันว่ากระเบื้องผนังเดิมยังอยู่ในสภาพดีพอที่จะคงไว้ได้ (ไม่มีกระเบื้องหลุดร่อน ไม่มียาแนวแตกร้าวที่จะบังคับให้ต้องทำงานผนังบางส่วน) หากต้องซ่อมแซมเล็กน้อย ให้แจ้งเป็นรายการเสริมแยกต่างหาก
- **วาล์วปิดน้ำฝักบัว / การตัดน้ำเข้า** — ยืนยันว่าสามารถตัดน้ำที่อ่างล้างหน้าและฝักบัวได้ที่วาล์วเดิมระหว่างการรื้อกระเบื้องพื้น โดยไม่ต้องย้ายแนวท่อใด ๆ
