# Bathroom Retile - Laem Chabang

Phase 02 work. Replace the tiles in the bathroom (and the separate toilet room, if applicable), and replace the basin. Source everything from one supplier to keep cost down — likely Thai Watsadu, HomePro, or a local tile shop.

This spec is **Phase 02 only** — see [PHASES](AAA-PHASES.md).

**Quote rule:** this file is **one quote line item**. The builder gives a single number for the **BATHROOM RETILE TOTAL** — not bundled with any other spec, not split across files. 1:1 mapping between this spec and the quote.

## Phase 02 — what gets done

### Bathroom tiles

- Strip existing wall and floor tiles in the bathroom.
- Lay new tiles, wall + floor.
- Re-grout, re-silicone wet edges.

## Phase 02 scope is fixed — nothing else

The Phase 02 quote must cover **only** the items above. Do not add anything else
to the quote. In particular:

- **No painting.** Joe and Mon will paint themselves if any paint work is wanted. No paint or paint labour in the quote.
- **No new plumbing or fixtures** beyond the basin replacement listed above.
- **No ceiling, light, or vent work** in the bathroom or toilet.
- **No bedroom/bathroom dividing wall work** — that wall stays untouched and is the future home of the wall-hung shelves; see [BEDROOM](BEDROOM.md).

If the builder believes extra work is needed (for example, a leak found behind tiles during strip-out), raise it separately before quoting — do not bundle it into this Phase 02 line item.
