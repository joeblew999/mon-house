# Windows & Door — Phase 01: Functional Fix

Phase 01 work, do now. Minimal functional fix so air conditioning works and the front door is usable. Phase 02 (full replacement) is a separate spec — see [WINDOWS-02](WINDOWS-02.md).

The old timber windows are skewed. We are not sealing them, not painting them, not replacing them. Just screw them shut. The screws alone give enough air seal for AC to be effective.

---

## Windows

For the 5 main windows:

- Screw the windows into the sub-frame. This pulls the windows closed and removes the skew.
- Remove the fly wire screens.
- Remove the steel security mesh.
- No sealant. No foam. No silicone. No paint.

Bathroom window: do not touch in Phase 01.

## Existing sliding door (front)

- Fix the lock. Supply 2 keys.
- Remove the heavy steel mesh behind the door.
- Do not replace the door. Nothing else needed.

## Same-visit dependency: external power outlet

Once the windows are screwed shut, any cable currently routed through a window
is cut off. The outdoor fan and outdoor washing machine need an external power
outlet installed **at the same visit** as the window-sealing work.

- New external power outlet, IP-rated for outdoor use, mounted on the exterior wall.
- Feed by **tapping off the existing kitchen outlet circuit** (the inside power outlet currently used) — no new run from the consumer unit.
- Mount the new outlet at the **same height as the existing inside outlet** so no conduit is needed, and the outlet sits clear of any water on the ground.
- Capacity: enough for **2 appliances simultaneously** (outdoor fan + outdoor washing machine). 2-gang outlet, or single outlet via a short outdoor-rated power strip.
- Proper fuse on the circuit if it isn't already adequately protected for the added load.

---

## Phase 01 scope is fixed — nothing else

The Phase 01 quote must cover **only** the items listed above. Do not add
anything else to the quote. In particular:

- **No painting.** Joe and Mon will do all painting themselves. Do not
  include paint, paint prep, or any painting labour in the Phase 01 quote.
- No new windows.
- No new front door.
- No sealants, foam, or silicone.
- No bathroom window work.
- Nothing from [Phase 02](WINDOWS-02.md).

If the builder believes extra work is needed, raise it separately before
quoting — do not bundle it into Phase 01.
