# สเปคด่วน — บ้านแหลมฉบัง

เอกสารข้อกำหนดงานก่อสร้าง แต่ละสเปคเขียนเป็นภาษาอังกฤษ แปลเป็นภาษาไทยโดยอัตโนมัติ และรวบรวมเป็น PDF

---

## ไฟล์สเปค

| ไฟล์ | คำอธิบาย |
|---|---|
| [GATE.md](GATE.md) | เปลี่ยนประตูรั้วบานเลื่อน |
| [METAL.md](METAL.md) | งานแผ่นหลังคาและโครงเหล็ก |
| [CONCRETE.md](CONCRETE.md) | งานคอนกรีต |
| [CEILING.md](CEILING.md) | งานฝ้าเพดาน |
| [PAINT.md](PAINT.md) | งานทาสี |
| [WINDOWS.md](WINDOWS.md) | งานหน้าต่าง |

---

## คำสั่งที่ใช้บ่อย

### สร้างสเปคทีละไฟล์
```
mise run one -- GATE
mise run one -- METAL
```
แปลเป็นภาษาไทย + สร้าง PDF ทั้งภาษาอังกฤษและภาษาไทยไปที่ `out/`

### สร้างสเปคทั้งหมด
```
mise run all
```

### แปลภาษาอย่างเดียว (ไม่สร้าง PDF)
```
mise run translate
```

### เฝ้าดูการเปลี่ยนแปลง (สร้างใหม่อัตโนมัติ)
```
mise run watch
```

### ล้างโฟลเดอร์ผลลัพธ์
```
mise run clean
```

---

## ผลลัพธ์

PDF จะถูกเขียนไปที่ `out/`:
- `out/GATE.pdf` — ภาษาอังกฤษ
- `out/GATE.th.pdf` — ภาษาไทย

---

## การเพิ่มสเปคใหม่

1. สร้าง `NEWSPEC.md` พร้อม frontmatter:
```markdown
---
title: My Spec
status: Draft
rev: "1"
---
```
2. รัน `mise run one -- NEWSPEC`

---

## ฟิลด์ Frontmatter

| ฟิลด์ | ค่าที่ใช้ได้ | หมายเหตุ |
|---|---|---|
| `title` | ข้อความใดก็ได้ | แสดงในส่วนหัวและส่วนท้าย |
| `status` | `Draft` / `For Review` / `Approved` | แสดงในส่วนท้าย |
| `rev` | `"1"`, `"2"` เป็นต้น | แสดงในส่วนท้าย |

## โครงสร้างโฟลเดอร์

```
quick/
├── mise.toml          # Task runner (กำหนดคำสั่งทั้งหมดที่นี่)
├── README.md          # ไฟล์นี้
├── GATE.md            # ไฟล์สเปค (ต้นฉบับภาษาอังกฤษ)
├── GATE.th.md         # คำแปลภาษาไทยที่สร้างอัตโนมัติ
├── images/            # รูปภาพทั้งหมด
├── scripts/
│   ├── translate.py   # สคริปต์แปลภาษาด้วย AI
│   └── theme.typ      # ธีม PDF (ส่วนหัว ส่วนท้าย สไตล์)
└── out/               # PDF ที่สร้างแล้ว
```
