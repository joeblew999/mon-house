## 📂 Repository Structure / โครงสร้าง

```
mon-house/
├── drawings/
│   ├── en/            # English documentation + drawings
│   └── th/            # Thai documentation + drawings (เอกสารภาษาไทย)
│
└── furniture/
    ├── SPEC.md        # Master index (all categories)
    ├── bathroom/      # Section 2.x
```
