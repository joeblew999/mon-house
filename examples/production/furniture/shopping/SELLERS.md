## Search Strategy

When researching a product:

1. **Start with COTTO official** - Get exact model numbers
2. **Search HomePro** - Usually has best prices with delivery
3. **Check OneStockHome** - Often cheapest for bulk/project orders
4. **Compare Lazada/Shopee** - Check official shops for deals
5. **Thai Watsadu** - Budget alternatives

**Search Query Template:**
```
{brand} {model} site:{domain} Thailand price
```

**Example:**
```
COTTO SC19517 site:onestockhome.com Thailand price
```
