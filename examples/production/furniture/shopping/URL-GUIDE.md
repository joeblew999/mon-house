# Product URL Guide

**Purpose**: How to find and add product URLs to shopping files

---

## URL Sources (Priority Order)

### 1. HomePro Online (BEST - Most Reliable)
**Website**: https://www.homepro.co.th/

**How to Search:**
1. Go to homepro.co.th
2. Search product name (e.g., "COTTO C024 basin")
3. Copy URL from product page
4. URL format: `https://www.homepro.co.th/p/[product-code]/[product-name]`

**Example Searches:**
- "COTTO wall basin" - for basins
- "COTTO shower mixer" - for shower taps
- "กระเบื้องห้องน้ำ" - for bathroom tiles
- "เครื่องทำน้ำอ้อน" - for water heaters

### 2. Lazada Thailand
**Website**: https://www.lazada.co.th/

**URL Format**: `https://www.lazada.co.th/products/[product-name]-[numbers].html`

**Good For:**
- Comparing prices
- Reading reviews
- Delivery options

### 3. Shopee Thailand
**Website**: https://shopee.co.th/

**URL Format**: `https://shopee.co.th/[product-name]-i.[shop-id].[product-id]`

**Good For:**
- Budget options
- Flash sales
- Free shipping deals

### 4. Manufacturer Websites
- **COTTO**: https://www.cotto.com/th/
- **American Standard**: https://www.americanstandard.co.th/
- **TOTO**: https://th.toto.com/

---

## How to Add URLs to Shopping Files

### Format in Markdown:

```markdown
**Where to Buy Online:**
- **HomePro**: [Product Name](https://www.homepro.co.th/p/...)
- **Lazada**: [Product Name](https://www.lazada.co.th/products/...)
- **Shopee**: [Product Name](https://shopee.co.th/...)
- **Manufacturer**: [COTTO Product Page](https://www.cotto.com/...)
```

### Example (Basin):

```markdown
**Where to Buy Online:**
- **HomePro**: [COTTO C024 Basin](https://www.homepro.co.th/p/cotto-c024-wall-basin)
- **Lazada**: [COTTO Wall Basin 55cm](https://www.lazada.co.th/products/...)
- **COTTO Direct**: [C024 Product Page](https://www.cotto.com/th/products/c024)
```
