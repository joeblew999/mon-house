## Installation Notes

### Bathroom Wall Tiling
- Tile to 1.5m height only (not full height)
- Install AFTER floor tiles are done
- Start from bottom, work up
- Use tile spacers for consistent gaps
- Install edge trim at top to finish

### Cutting Notes
- Will need cuts around:
  - Door frame
  - Basin/sink area
  - Shower fixtures
  - Toilet area
