## Installation

### Location
| | |
|---|---|
| **Position** | Along short wall (1000mm), behind toilet |
| **Length** | 1 unit × 100cm = full wall coverage |
| **Connection** | To existing drainage point (2-2.5" PVC) |

### Floor Gradient
- Floor must slope toward drain
- Test with golf ball - should roll to drain
- Gradient: 1-2% slope

### Builder Notes
- **Dig out area** to make room for drain body
- Install DURING floor tiling (not after)
- Waterproof membrane must seal around drain
- Test for leaks before finishing tiles
