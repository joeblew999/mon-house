## 6.1 Electric Scooter

**Product Information**
- **Type**: Electric scooter/e-bike (รถจักรยานยนต์ไฟฟ้า)
- **Brand**: Yadea
- **Model**: OVA
- **Style**: Modern retro, elegant design
- **Target**: Designed for women, comfortable for daily commuting

**Specifications**

| Specification | Value |
|---------------|-------|
| **Motor** | TTFAR Electric Motor, 600W |
| **Top Speed** | 42 km/h |
| **Battery** | TTFAR Graphene 48V/23Ah |
| **Range** | 60 km per charge |
| **Battery Life** | 1,000+ charging cycles (~20,000 km) |
| **Footrest** | 350 mm |
| **Seat Length** | 615 mm (dual seat) |
| **Brakes** | Front disc brake + rear drum brake |

**Features**
- 1 Second Smart Unlock (via Yadea app - sit down and go)
- Automatic headlights
- SOC Battery Monitoring
- Automatic parking system (P-mode)
- Reverse button and assist mode
- Traction Control System (TCS)
- Hill Descend Control (HDC)
- Lady Mode (gentler acceleration)
- Front-rear suspension
- Bolt-free body design (clothing-safe)
- 3-layer paint (fade-resistant for 3 years)
- Large windshield

**Colors Available**
- Retro Red
- Pearl Gold
- Noble Green
- Sakura Pink
- Mint Blue

**Warranty**
- 2 years or 20,000 km

**Placement**
- **Purpose**: Daily commuting, errands, short trips
- **Charging**: Standard home outlet (220V)
- **See also**: [External Power Outlets](../outdoor/SPEC.md#54-external-power-outlets) - builder requirements for outdoor charging
