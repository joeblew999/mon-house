# 8.2 ประตูห้องนอน

**อัปเดตล่าสุด**: 2025-01-04

[← กลับไปข้อกำหนดห้องนอน](../SPEC.th.md#82-ประตูห้องนอน)

---

## ความต้องการ

- **จำนวน**: 2 บาน (ห้องนอนละ 1 บาน)
- **ประเภท**: ประตูบานสวิงภายใน
- **ขนาด**: มาตรฐานไทย (80×200 ซม. หรือ 90×200 ซม.)
- **กุญแจ**: ล็อคความเป็นส่วนตัว (แบบห้องนอน)

> ⚠️ **วัดประตูเดิมก่อน** - ขนาดมาตรฐานด้านล่างอาจไม่ตรงกับวงกบเดิมของคุณ!

---

## ขนาดประตูมาตรฐานประเทศไทย

| ขนาด | กว้าง | สูง | การใช้งาน |
|------|-------|-----|-----------|
| มาตรฐาน | 80 ซม. | 200 ซม. | ห้องนอนส่วนใหญ่ |
| กว้าง | 90 ซม. | 200 ซม. | ช่องเปิดใหญ่กว่า |

**หมายเหตุ**: ประตูมักขายไม่รวมวงกบ ถ้าเปลี่ยนเฉพาะประตู (ใช้วงกบเดิม) ให้วัดบานประตูเท่านั้น

---

## ตัวเลือกประตูตามประเภท

### 1. ประตูแกนกลวง (ประหยัด)

| | |
|---|---|
| **ประเภท** | ประตูภายในแกนกลวง |
| **วัสดุ** | ผิว MDF/HDF แกนรังผึ้ง |
| **ราคา** | ฿800-1,500 ต่อบาน |
| **น้ำหนัก** | เบา (~15-20 กก.) |
| **เสียง** | กันเสียงไม่ดี |

**ข้อดี**: ถูก เบา ติดตั้งง่าย
**ข้อเสีย**: รู้สึกบอบบาง กันเสียงไม่ดี บุบง่าย

**ซื้อที่ไหน**: HomePro, ไทวัสดุ, Global House

---

### 2. ประตูแกนตัน (แนะนำ)

| | |
|---|---|
| **ประเภท** | ประตูภายในแกนตัน |
| **วัสดุ** | แกน MDF/ไม้อัดพร้อมวีเนียร์ |
| **ราคา** | ฿1,500-3,000 ต่อบาน |
| **น้ำหนัก** | ปานกลาง (~25-35 กก.) |
| **เสียง** | กันเสียงดี |

**ข้อดี**: รู้สึกคุณภาพดีกว่า กันเสียงดี ทนทานกว่า
**ข้อเสีย**: หนักกว่า แพงกว่า

**ซื้อที่ไหน**: HomePro, บุญถาวร

**คำแนะนำ**: คุ้มค่าที่สุดสำหรับประตูห้องนอน

---

### 3. ประตูวีเนียร์ไม้ (ราคากลาง)

| | |
|---|---|
| **ประเภท** | ประตูวีเนียร์ไม้ |
| **วัสดุ** | วีเนียร์ไม้จริงบนแกนตัน |
| **ราคา** | ฿2,000-4,000 ต่อบาน |
| **ผิว** | ลายไม้ธรรมชาติ |

**ข้อดี**: ดูเหมือนไม้จริง คุณภาพดี
**ข้อเสีย**: แพงกว่า อาจต้องดูแลมากกว่า

---

### 4. ประตูไม้จริง (พรีเมียม)

| | |
|---|---|
| **ประเภท** | ประตูไม้จริง |
| **วัสดุ** | ไม้จริงทั้งบาน |
| **ราคา** | ฿4,000-10,000+ ต่อบาน |
| **น้ำหนัก** | หนัก (~40-60 กก.) |

**ข้อดี**: คุณภาพพรีเมียม ทนทานที่สุด สวยงาม
**ข้อเสีย**: แพง หนัก อาจบิดงอถ้าไม่ทำสีดี

---

## อุปกรณ์ประตู (ซื้อแยก)

### มือจับพร้อมล็อคความเป็นส่วนตัว

| | |
|---|---|
| **ประเภท** | มือจับก้านโยกพร้อมล็อค |
| **ล็อค** | ปุ่มกดหรือปุ่มหมุน |
| **ราคา** | ฿200-800 ต่อชุด |
| **สี** | โครเมียม, นิกเกิลด้าน, หรือดำ |

**หมายเหตุ**: ประตูห้องนอนต้องมีล็อคความเป็นส่วนตัว (ล็อคจากในได้ ปลดจากนอกได้ด้วยเครื่องมือ)

---

### บานพับ (ถ้าไม่รวม)

| | |
|---|---|
| **ประเภท** | บานพับประตู |
| **ขนาด** | 4" × 3" (มาตรฐาน) |
| **จำนวน** | 3 ต่อประตู |
| **ราคา** | ฿50-150 ต่อตัว |
| **สี** | ให้ตรงกับมือจับ |

## หมายเหตุการติดตั้ง

**ทำเองได้ถ้า:**
- ขนาดเท่าประตูเดิม
- ใช้วงกบเดิม
- มีเครื่องมือพื้นฐาน (สว่าน, ไขควง)

**จ้างช่างถ้า:**
- ขนาดต่างจากเดิม
- ต้องแก้ไขวงกบ
- ต้องการงานสวย

**ค่าติดตั้ง**: ฿500-1,000 ต่อบาน

---

## สรุป

**ซื้อ**: 2 × ประตูภายในแกนตัน (80×200 ซม. หรือวัดก่อน)
**ราคาประมาณ**: ~฿5,000-6,000 (ประตู + อุปกรณ์)
**ที่ไหน**: HomePro หรือไทวัสดุ

**ขั้นตอน**:
1. วัดวงกบประตูเดิม
2. ไป HomePro/ไทวัสดุ
3. เลือกประตูแกนตันขนาดตรง
4. ซื้อมือจับพร้อมล็อคความเป็นส่วนตัว
5. ติดตั้ง (ทำเองหรือจ้าง)
