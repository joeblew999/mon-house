# 8.2 Bedroom Doors

**Last Updated**: 2025-01-04

[← Back to Bedroom SPEC](../SPEC.md#82-bedroom-doors)

---

## Requirements

- **Quantity**: 2 doors (one per bedroom)
- **Type**: Interior swing door
- **Size**: Standard Thailand (80×200 cm or 90×200 cm)
- **Lock**: Privacy lock (bedroom style)

> ⚠️ **MEASURE EXISTING DOORS FIRST** - Standard sizes listed below may not match your existing frames!

---

## Standard Thailand Door Sizes

| Size | Width | Height | Use |
|------|-------|--------|-----|
| Standard | 80 cm | 200 cm | Most bedrooms |
| Wide | 90 cm | 200 cm | Larger openings |

**Note**: Doors are typically sold without frame. If replacing door only (keeping frame), measure the door leaf itself.

---

## Door Options by Type

### 1. Hollow Core Door (Budget)

| | |
|---|---|
| **Type** | Hollow core interior door |
| **Material** | MDF/HDF skin with honeycomb core |
| **Price** | ฿800-1,500 per door |
| **Weight** | Light (~15-20 kg) |
| **Sound** | Poor sound insulation |

**Pros**: Cheap, lightweight, easy to install
**Cons**: Feels flimsy, poor soundproofing, dents easily

**Where to Buy**: HomePro, Thai Watsadu, Global House

---

### 2. Solid Core Door (Recommended)

| | |
|---|---|
| **Type** | Solid core interior door |
| **Material** | MDF/particle board core with veneer |
| **Price** | ฿1,500-3,000 per door |
| **Weight** | Medium (~25-35 kg) |
| **Sound** | Good sound insulation |

**Pros**: Better quality feel, good soundproofing, more durable
**Cons**: Heavier, more expensive

**Where to Buy**: HomePro, Boonthavorn

**Recommendation**: Best value for bedroom doors

---

### 3. Wood Veneer Door (Mid-Range)

| | |
|---|---|
| **Type** | Wood veneer door |
| **Material** | Real wood veneer on solid core |
| **Price** | ฿2,000-4,000 per door |
| **Finish** | Natural wood grain |

**Pros**: Real wood appearance, good quality
**Cons**: More expensive, may need more care

---

### 4. Solid Wood Door (Premium)

| | |
|---|---|
| **Type** | Solid wood door |
| **Material** | Real wood throughout |
| **Price** | ฿4,000-10,000+ per door |
| **Weight** | Heavy (~40-60 kg) |

**Pros**: Premium quality, best durability, beautiful
**Cons**: Expensive, heavy, may warp if not properly finished

---

## Door Hardware (Separate Purchase)

### Door Handle with Privacy Lock

| | |
|---|---|
| **Type** | Lever handle with privacy lock |
| **Lock** | Push-button or turn-button privacy |
| **Price** | ฿200-800 per set |
| **Finish** | Chrome, satin nickel, or black |

## Installation Notes

**DIY Possible If:**
- Same size as existing door
- Keeping existing frame
- Have basic tools (drill, screwdriver)

**Hire Installer If:**
- Different size than existing
- Need to modify frame
- Want professional finish

**Installation Cost**: ฿500-1,000 per door
